04

PID Controller

Monetary policy engine. Dynamic emission targeting.

E(t) = Kp·e(t) + Ki·∫e(τ)dτ + Kd·de(t)/dt
e(t) = Target TVL − Actual TVL
Kp = Proportional gain (immediate response)
Ki = Integral gain (steady-state correction)
Kd = Derivative gain (dampening)

Parameters

Target TVLGovernance-set
Emission RatePID-computed, per epoch
Oracle SourceAvOracle v5 (TWAP-primary)
TVL SourceSlipstream LP + Treasury
Reserve Ratio60% of deposits
Epoch5 days

P — Proportional

Reacts to the current gap. Bigger gap means harder push toward target.

I — Integral

Accumulates past error. Eliminates steady-state offset over time.

D — Derivative

Predicts future error. Dampens oscillations and overshoot.
