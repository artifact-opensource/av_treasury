# Etherscan V2 Verification Guide

## Overview

AV Treasury uses **Etherscan's V2 verification API** for Base mainnet contract verification. The V2 API provides a unified endpoint across all Etherscan-supported chains.

## Key Differences from V1

| Aspect | V1 (Deprecated) | V2 (Current) |
|--------|-----------------|--------------|
| API Endpoint | `https://api.basescan.org/api` | `https://api.etherscan.io/v2/api?chainid=8453` |
| API Key | Chain-specific | Unified (works across all chains) |
| Constructor Args | ABI-encoded hex | ABI-encoded hex (same format) |
| Rate Limit | Per-chain | Unified |
| Verification URL | `basescan.org/verify` | `basescan.org/verify` (same UI) |

## Prerequisites

1. **Foundry toolchain** (`forge`, `cast`) installed
2. **Etherscan API key** — Get from https://etherscan.io/myapikey
3. **Deployed addresses JSON** — Generated by `DeployProduction.s.sol`

## Environment Variables

```bash
export ETHERSCAN_API_V2="your_etherscan_api_key"
export DEPLOYER_ADDRESS="0x..."  # Deployer address (for constructor args)
export AERODROME_ROUTER="0x..."   # Aerodrome router on Base mainnet
```

## Usage

### Step 1: Deploy (generates deployed_8453.json)

```bash
forge script scripts/DeployProduction.s.sol:DeployProduction \
  --sig "run()" \
  --rpc-url $BASE_RPC_URL \
  --private-key $DEPLOYER_PRIVATE_KEY \
  --broadcast \
  --verify \
  --verifier etherscan \
  --verifier-url "https://api.etherscan.io/v2/api?chainid=8453" \
  --etherscan-api-key $ETHERSCAN_API_V2 \
  -vvvv
```

### Step 2: Verify (if --verify didn't work during deploy)

```bash
bash scripts/verify-all.sh deployed_8453.json
```

Or manually for each contract:

```bash
# AgToken (no constructor args)
forge verify-contract \
  --chain-id 8453 \
  --verifier etherscan \
  --verifier-url "https://api.etherscan.io/v2/api?chainid=8453" \
  --etherscan-api-key $ETHERSCAN_API_V2 \
  --watch \
  <ADDRESS> \
  contracts/AgToken.sol:AgToken

# TreasuryAMO (with constructor args)
forge verify-contract \
  --chain-id 8453 \
  --verifier etherscan \
  --verifier-url "https://api.etherscan.io/v2/api?chainid=8453" \
  --etherscan-api-key $ETHERSCAN_API_V2 \
  --constructor-args $(cast abi-encode "constructor(address,address,address,address)" $AU_TOKEN $AG_TOKEN $AERODROME_ROUTER $DEPLOYER) \
  --watch \
  <ADDRESS> \
  contracts/TreasuryAMO.sol:TreasuryAMO
```

## Constructor Arguments Reference

| Contract | Constructor Signature | Args Source |
|----------|----------------------|-------------|
| AgToken | `()` | None (uses `initialize()`) |
| AuToken | `()` | None (uses `initialize()`) |
| AvOracle | `(auToken, agToken, admin, governor)` | Deploy script |
| PID_Controller | `(admin, staking, agToken, targetTVL, kp, ki, kd)` | Deploy script |
| AVLPStaking | `()` | None (uses `initialize()`) |
| TreasuryAMO | `(auToken, reserveToken, aerodromeRouter, admin)` | Deploy script + env var |
| ArtifactTimelock | `(proposer, executor, canceler)` | Deploy script |

## Common Verification Failures

### 1. "Constructor arguments mismatch"
- **Cause**: The constructor args used for verification don't match what was passed during deployment
- **Fix**: Use the exact same values. The verification script reads from the deployed JSON.

### 2. "Compiled bytecode doesn't match"
- **Cause**: Compiler version or optimization settings differ
- **Fix**: Use the same Solidity version (`0.8.26`) and optimizer settings as the deployment

### 3. "Already verified"
- **Cause**: Contract was previously verified
- **Fix**: No action needed. Check the block explorer.

### 4. "The deployed and recompiled bytecodes don't match"
- **Cause**: Source code changed after deployment
- **Fix**: Ensure you're verifying against the exact source code that was deployed

### 5. "Invalid API key"
- **Cause**: Using V1 API key or wrong key
- **Fix**: Use `ETHERSCAN_API_V2` env var with a valid unified API key

## Etherscan V2 Specifics

The V2 API:
- Uses a single endpoint: `https://api.etherscan.io/v2/api`
- Requires `chainid` as a query parameter
- Accepts the same API key format as V1
- Supports all Etherscan-supported chains (Base, Ethereum, BSC, etc.)

For Base mainnet specifically:
- Chain ID: `8453`
- Full URL: `https://api.etherscan.io/v2/api?chainid=8453`
- Block explorer: `https://basescan.org`

## Troubleshooting

### Verification succeeds but source not shown
- Wait 1-2 minutes for Etherscan to index
- Check at `https://basescan.org/address/<contract>#code`

### "Bytecode match but source code shows as decompiled"
- This means the metadata hash doesn't match
- Ensure the compiler version matches exactly (including commit hash)
- Check that optimization settings match

### Need to re-verify after code changes
- You cannot re-verify with different source code
- Must redeploy the contract
